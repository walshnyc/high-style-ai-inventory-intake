HIGH STYLE AI — VERSION 3.6.5
REVIEW ACTION BUTTONS

WHAT CHANGED

The final review section now displays three buttons side by side:

1. Approve & Send to Google Sheet
   - Saves the approved item permanently to Master_Inventory.
   - Adds it to the correct monthly Shoot List.
   - Moves the source draft to Approved.

2. Save Draft
   - Saves all current AI-generated information.
   - Saves every edit made in the review form.
   - Keeps the item in Review.
   - Does not add the item to Master_Inventory.
   - Does not add it to the monthly Shoot List.
   - Does not mark it Approved.

3. Clear and Start New Entry
   - Clears the current item and starts a new intake.
   - Replaces the less descriptive “New Entry” / “Submit Another Entry” wording.

The saved review draft includes:
- current title and description
- suggested and approved price entries
- category, subcategory, style, period, and country
- designer or maker
- materials
- dimensions
- condition notes
- price-tag text
- SEO keywords
- internal review notes
- AI history and learning context already supported by Version 3.6.4

INSTALLATION

This is a frontend-only update.

1. Unzip this package.
2. Upload the files inside the folder to the existing GitHub repository.
3. Replace matching files.
4. Commit the update.
5. Allow Streamlit to redeploy.

No Google Apps Script change is required.
Continue using Backend Version 3.5.2.
